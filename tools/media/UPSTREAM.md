# Upstream

`viventium_media/` (engine.py, images.py, video.py) is main Viventium's local media package, `viventium-media`
0.1.3 (`viventium_v0_4/MCPs/local-media/src/viventium_media`), copied as it is: the qualified commands for each
model, one render at a time, and the check that what came out is a real picture or video.

Not taken: its MCP server. Here a Worker of any kind runs one command from its shell instead (`make`).
Local edits: none. To update, copy the three files again and run a picture.
