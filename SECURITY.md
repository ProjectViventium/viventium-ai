# Security

Report suspected vulnerabilities through this repository’s **Security → Report a vulnerability**
([GitHub private vulnerability reporting](../../security/advisories/new)). Do not post exploit details
in public issues, pull requests or comments. Repository maintainers must enable private reporting
before public release.

Include the installed version or revision, macOS version, setup and processing mode, expected and
observed behavior, and a minimal reproduction with synthetic data. Remove credentials, tokens,
signed links, personal information and unrelated logs. Test only systems you own or have permission
to assess.

Include your version even if it is old. No supported-version window, response deadline or bounty
is promised. Use this repository’s Issues for ordinary bugs without a security impact.
