## When

The turn contains a real quantitative question, or an answer that depended on arithmetic, a probability, a rate, units or an estimate, where a wrong number would change the conclusion.

Not for numbers that are only dates, prices or counts mentioned in passing.

## Then

Work the numbers properly. Restate the problem exactly, state the assumptions, calculate step by step (run code if you can), and check the result against common sense and limits. Compare it with any number in the answer that was given.

Hand back the result with its units and how sure you are, and say clearly if the given number was wrong and by how much. If the given number holds, hand back nothing.
